
# Talento Lab Ecommerce

Proyecto de pre-entrega del curso **Front-End JavaScript de Talento Tech**.

Talento Lab Ecommerce es un sitio web de comercio electrónico desarrollado con HTML5 y CSS3. El objetivo es aplicar los conocimientos de estructura semántica, diseño visual, Flexbox, CSS Grid y diseño responsive.

## Sitio publicado

- **Demo:** https://roxanaberesaga.github.io/pre_entrega_roxana_beresaga/
- **Repositorio:** https://github.com/RoxanaBeresaga/pre_entrega_roxana_beresaga

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts (Roboto)
- Font Awesome
- Git y GitHub
- GitHub Pages
- Formspree para el formulario de contacto

## Funcionalidades implementadas

### Página principal

- Menú de navegación.
- Banner principal con promociones.
- Catálogo de ocho productos.
- Banner de descuentos.
- Sección de testimonios.
- Formulario visual de suscripción al newsletter.
- Footer con información de contacto, redes sociales y medios de pago.

### Página de Contacto

- Formulario con campos de nombre, correo electrónico y mensaje.
- Validación básica mediante atributos HTML.
- Envío de consultas mediante Formspree.
- Diseño adaptado a diferentes tamaños de pantalla.
- Navegación hacia la página principal.

## Diseño responsive

El sitio fue desarrollado para adaptarse a distintos dispositivos mediante Flexbox, CSS Grid y media queries.

Se realizaron pruebas visuales en las siguientes resoluciones:

- Escritorio: 1024 × 768 px.
- Tablet: 768 × 1024 px.
- Celular: 360 × 780 px.

## Cómo ejecutar el proyecto

1. Clonar el repositorio:

   `git clone https://github.com/RoxanaBeresaga/pre_entrega_roxana_beresaga.git`

2. Abrir la carpeta del proyecto en Visual Studio Code.

3. Abrir `index.html` en el navegador o utilizar la extensión Live Server.

También se puede acceder directamente a la versión publicada en GitHub Pages.

## Funcionalidades pendientes

Este proyecto corresponde a una pre-entrega enfocada en HTML y CSS.

Las siguientes funcionalidades no están implementadas en esta etapa:

- Carrito de compras y botones de agregar productos.
- Registro e inicio de sesión.
- Suscripción funcional al newsletter.
- Páginas de Blog y Acerca de.
- Procesamiento de pagos.

Los productos, precios y datos comerciales se presentan con fines demostrativos.
